# Административный веб-UI

## Статус

**Черновик.** Реализация — позже.

## Стек

- HTML-шаблоны (`html/template`), встроенные в бинарник через `//go:embed`.
- htmx 4.0 — динамика без полной перезагрузки.
- Bootstrap 5.2 — вёрстка.
- Локализация: `go-i18n/v2` (ru, lv, en).
- Авторизация: `none` или `oidc` (`coreos/go-oidc/v3`).

## Страницы (план)

- `/` — дашборд: статус модема.
- `/inbox` — входящие.
- `/outbox` — исходящие.
- `/compose` — отправить SMS.
- `/logs` — живой хвост логов через SSE.

## Локализация

Определение языка: `?lang=xx` → cookie `lang` → `Accept-Language` →
`WEBUI_DEFAULT_LANG`. Переключатель — в navbar.
