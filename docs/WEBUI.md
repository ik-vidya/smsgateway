# Административный веб-UI

Встроенный веб-интерфейс для управления smsgateway. Работает на
отдельном порту (`WEBUI_ADDR`, по умолчанию `127.0.0.1:8081`),
включается через `WEBUI_ENABLED=true`.

## Стек

- `html/template` — шаблоны встроены в бинарник через `//go:embed`.
- Bootstrap 5.2.3 — вёрстка; хранится локально в
  `internal/webui/static/vendor/bootstrap/`.
- htmx 4.0 — динамика без полной перезагрузки; локально в
  `internal/webui/static/vendor/htmx/`.
- `go-i18n/v2` — локализация (ru/lv/en).
- Нативный `EventSource` (SSE) — для живых потоков логов и портов.

CSP: `default-src 'self'` (никаких CDN). CSRF: `SameSite=Lax`
на cookie + проверка `Origin`/`Referer` в middleware для
не-GET запросов.

## Авторизация

Поддерживаются два режима (`WEBUI_AUTH_MODE`):
- **none** (по умолчанию) — без авторизации. Безопасно только для
  localhost или доступа через SSH-туннель.
- **basic** — HTTP Basic Auth. Требует `WEBUI_AUTH_USER` и
  `WEBUI_AUTH_PASS`. Браузер запрашивает логин и пароль при входе.

Пример для `.env`:

~~~env
WEBUI_AUTH_MODE=basic
WEBUI_AUTH_USER=admin
WEBUI_AUTH_PASS=your_strong_password
~~~

## Страницы

### `/` — Dashboard
Состояние сервиса и модема.
- **Модем**: два независимых бейджа: «порт открыт» и «в сети».
- **База данных**: путь, health, uptime, статус Gammu.
- **Счётчики**: количество сообщений по статусам.

### `/inbox` и `/outbox`
Списки сообщений с фильтрами и пагинацией.
- **Фильтры**: номер, статус, дата с/по, **и поиск по тексту**.
- **Пагинация**: limit 50, максимум 500.
- **htmx**: фильтры и пагинация работают без полной перезагрузки.
- **Текст SMS**: `<details>/<summary>` для раскрытия полного текста.

**Незавершенные сообщения** (только для `/inbox`):
Если сеть доставила не все части длинного SMS, они висят в
`pending_parts`. В этом случае над таблицей появляется желтый
блок «Незавершенные сообщения», в котором можно раскрыть детали
и посмотреть, какие части (seq) уже пришли и их текст.

### `/messages/{id}` — Детали сообщения
Показывает полную информацию о сообщении и историю Delivery Reports.

**Действия**:
- Если статус `failed` — кнопка **«Повторить»** (создаёт копию
  сообщения в очереди).
- Если статус `queued` — кнопка **«Отменить»** (переводит в
  `failed` с пометкой «Отменено пользователем»). Если `sendLoop`
  уже забрал сообщение (`sending`), отмена вернёт ошибку.

### `/compose`
Форма отправки SMS. POST `/compose` ставит сообщение в очередь
через `Service.EnqueueOutgoing` и редиректит на `/compose?sent=1`.
Поддерживаются длинные SMS (автоматически разбиваются на части).

### `/logs`
Live-поток логов через SSE. Подключается к `/logs/stream`,
рисует записи в DOM (лимит 2000 строк, старые вытесняются).

Управление:
- фильтр по уровню;
- пауза/возобновление;
- очистка;
- поиск по подстроке;
- автопрокрутка вниз (отключается, если прокрутить вверх).

### `/setup`
Настройка модема и проверка его состояния.

**Обнаруженные порты**: SSE-поток из `/dev/serial/by-id/` (fallback
`/dev/ttyUSB*`, `/dev/ttyACM*`). На активном порту (совпадает с
`SERIAL_PORT`) отображается бейдж «используется сервисом» вместо
кнопки «Проверить».

**Диагностика модема**: кнопка «Обновить» вызывает
`diagnostics.Collect` через сервис. Показывает таблицу с SIM,
сигналом, регистрацией, оператором, SMSC, хранилищем.

**Отправка + приём**: кнопка «Запустить» отправляет тестовую SMS
на `SELF_NUMBER` и ждёт её возврата (входящее сообщение). Проверяет
оба направления end-to-end. Результат дублируется в Telegram.

**Hot-reload**: кнопка «Сохранить и перезапустить» пишет
`SERIAL_PORT` в `.env` и шлёт `SIGHUP` процессу. `main.go` делает
graceful shutdown и `syscall.Exec`, PID сохраняется.

### `/lang/{code}`
Установка cookie `lang` и редирект на главную. Определение языка:
`?lang=xx` → cookie → `Accept-Language` → `WEBUI_DEFAULT_LANG`.

## Ограничения

- **OIDC не реализован.** `WEBUI_AUTH_MODE=basic` закрывает
  базовые потребности.
- **`WriteTimeout=0`** у webui-сервера — SSE-потоки живут дольше
  обычных запросов.
- **Flash SMS** (`f` в расширении OUT-файла Gammu) не
  поддерживается на уровне `pdu.Build`.
- **htmx 4.0 SSE extension** не используется — нативный
  `EventSource` даёт полный контроль.
