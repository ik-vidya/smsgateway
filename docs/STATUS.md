# Статус проекта

**Дата последнего обновления:** 2026-10-20.
**Версия:** `v1.1.0`.

`smsgateway` — готовый к продакшену SMS-шлюз. Все заявленные
компоненты реализованы, покрыты тестами и проверены на живом
оборудовании (SIM800L). Безопасность (Basic Auth) и интеграция
с внешними системами (Gammu DR) настроены.

## Реализовано в v1.1.0

### Основное
- Приём и отправка SMS (включая multipart).
- HTTP/JSON REST API.
- Web UI с Basic Auth.
- Gammu file backend (включая создание DR-файлов в `inbox`).
- SQLite (миграции, retention).

### Новое в v1.1.0
- **Basic Auth** для Web UI (`WEBUI_AUTH_MODE=basic`).
- **Поиск по тексту** в Inbox/Outbox.
- **Кнопки «Отменить»** (для queued) и **«Повторить»** (для failed).
- **Сборка длинных SMS** (входящие и исходящие, с паузами).
- **Интеграция с АСУ ПП**: сохранение `gammu_serial` и `created_at`
  из имени файла, генерация `DELIVERED`/`FAILED` в `inbox`.
- **Улучшенная диагностика** ошибок отправки (логирование CREG/COPS/CSQ).
- **Безопасный деплой** (`make deploy`) с бэкапом и авто-откатом.

## Известные ограничения версии 1.1.0

1. **OIDC не реализован.** Для внутренней сети достаточно Basic Auth.
2. **`AT+CREG=1` вместо `=2`.** `networkLoop` опрашивает раз в 30s.
3. **Flash SMS не поддерживается.**
4. **Встроенное автообновление отсутствует.** Безопаснее использовать
   `make deploy` (с бэкапом и авто-откатом).
